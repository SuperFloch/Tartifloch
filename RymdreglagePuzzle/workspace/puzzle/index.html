Puzzle des 64 grilles

Glisser une pièce sur une autre pour les intervertir (ou cliquer une pièce puis une autre). Pièce sélectionnée : boutons Tourner / Miroir, ou touches R (tourner), F (miroir), double-clic (tourner). Sauvegarde automatique dans le navigateur ; « Enregistrer » écrit aussi positions.json si le serveur (node server.js) tourne. Étiquette orange = pièce déplacée ou tournée. Pour voir une solution du solveur : « Charger » solution_rot.json.
